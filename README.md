# RDF & SPARQL Plugin for JetBrains IDEs — Public Issue Tracker & Roadmap

[![JetBrains Marketplace](https://img.shields.io/jetbrains/plugin/v/13838-rdf-and-sparql?label=JetBrains%20Marketplace)](https://plugins.jetbrains.com/plugin/13838-rdf-and-sparql)
[![Website](https://img.shields.io/badge/Website-rdfandsparql.com-blue)](https://rdfandsparql.com)

Welcome to the official public issue tracker and feature roadmap for the
**[RDF & SPARQL plugin for JetBrains IDEs](https://plugins.jetbrains.com/plugin/13838-rdf-and-sparql)** (IntelliJ IDEA,
PyCharm, WebStorm, DataGrip, GoLand, Rider, CLion, RustRover, and more).

> **Note:** This repository hosts our public **Issue Tracker** and **Roadmap**. The plugin's commercial source code is
> maintained in a private repository.

---

## 🚀 How to Participate

### 1. 👍 Vote on the Roadmap

Want to influence what we build next? Browse our
**[Open Roadmap Issues](https://github.com/rdfandsparql/jetbrains-rdf-and-sparql-plugin/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap)**
and react with a **👍 (`+1`)** on the top description of any feature you need in your daily workflow. You can also leave
a comment describing your specific triplestore, ontology setup, or file scale.

### 2. 💡 Request a Feature

Have an idea that isn't on the tracker yet?
**[Open a Feature Request](https://github.com/rdfandsparql/jetbrains-rdf-and-sparql-plugin/issues/new?template=feature_request.yml)**
and tell us about the workflow friction you're trying to solve.

### 3. 🐛 Report a Bug

* **Unhandled IDE Exceptions:** The fastest way to report an exception is using the built-in **1-click Error Reporting**
  dialog inside your JetBrains IDE ([see guide](https://rdfandsparql.com/docs/reporting-issues#error-reporting-in-ide)).
* **Syntax, Completion, or Endpoint Bugs:**
  **[Open a Bug Report](https://github.com/rdfandsparql/jetbrains-rdf-and-sparql-plugin/issues/new?template=bug_report.yml)**
  with a minimal reproducible RDF/SPARQL snippet.

### 4. 🔒 Private & Enterprise Support

Working with proprietary ontologies, private enterprise endpoints (GraphDB, Stardog, AWS Neptune, RDFox, AllegroGraph),
or licensing questions that you cannot share publicly?

* Email us directly at **[support@rdfandsparql.com](mailto:support@rdfandsparql.com)**.
